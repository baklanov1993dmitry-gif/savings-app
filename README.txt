МОИ НАКОПЛЕНИЯ — установка на телефон и компьютер (≈10 минут, один раз)

1. Репозиторий с приложением (публичный — в нём нет ваших данных, только код)
   • github.com → New repository → имя, например: savings-app → Public → Create.
   • Add file → Upload files → перетащи ВСЕ файлы из этой папки (index.html, sw.js, manifest.webmanifest, 2 иконки) → Commit.
   • Settings → Pages → Source: Deploy from a branch → main / (root) → Save.
   • Через минуту приложение откроется по адресу https://ТВОЙ-ЛОГИН.github.io/savings-app/

2. Приватный репозиторий для данных (для синхронизации)
   • New repository → имя savings-vault → Private → Create.
   • Settings (аккаунта) → Developer settings → Personal access tokens → Fine-grained tokens → Generate:
       Repository access: Only select repositories → savings-vault
       Permissions → Contents: Read and write
   • Скопируй токен (показывается один раз).
   • В приложении: Настройки → Синхронизация → ТВОЙ-ЛОГИН/savings-vault + токен → Включить.

3. Второе устройство
   • Открой тот же адрес → «Подключить хранилище с другого устройства» → репозиторий + токен → введи мастер-пароль.

4. Установка как приложения
   • Телефон: меню браузера → «Установить приложение» / «На экран Домой».
   • Компьютер (Chrome/Edge): значок установки в адресной строке.

5. Вход по отпечатку: Настройки → Безопасность → «Включить вход по отпечатку» (на https, на каждом устройстве отдельно).

Важно: мастер-пароль и ключ восстановления — только у тебя. В репозитории лежит шифротекст; без пароля это случайные байты.
Токен храни как пароль: он даёт доступ к файлу (расшифровать его всё равно нельзя). Данные в браузере живут, пока не очищены данные сайта — подстраховка: Настройки → «Скачать зашифрованную копию».
